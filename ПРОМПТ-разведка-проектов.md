# ПРОМПТ: разведка проектов, которые усилят Moira (качественный поиск)

> Ты — исследователь экосистемы. Твоя задача — найти НЕ ПЕРВУЮ ПОПАВШУЮСЯ библиотеку, а реально сильные,
> живые и релевантные проекты, которые усилят конкретные узлы чат-бота Moira (telegram-таро-бот).
> Работа = исследование + отчёт в ОДИН файл. НЕ редактируй код проекта, НЕ запускай его.

## Роль и правило мышления
- Для каждого узла Moira ты ищешь 5–7 кандидатов, затем отбираешь 1–3 лучших по скоринговой матрице.
- НЕ доверяй первой странице выдачи поисковика, дешёвым статьям-агрегаторам и спискам «awesome-*» как источнику истины — только как отправной точке.
- Каждый факт о репозитории (звёзды, последний коммит, лицензия) проверяй ПО РЕАЛЬНОЙ СТРАНИЦЕ/API GitHub или PyPI (запросы через bash-curl: GET https://api.github.com/repos/{owner}/{repo} и GET https://pypi.org/pypi/{pkg}/json). Без токена лимит 60 запросов/час — экономь для финальной проверки ~10–15 репозиториев.
- Пиши на русском. Все факты давай с проверенными числами и URL.

## Стек Moira (что уже есть — под это ищем УСИЛЕНИЕ)
1. **LLM-слой**: `bot/llm/adapter.py` — instructor + AsyncOpenAI (OpenRouter-совместимый base_url), pydantic-модели CardInterpretation/TarotReadingResult, фоллбэк «встроенные толкования» при отсутствии LLM, память последних 3 чтений пользователя.
2. **Астрология**: `bot/astro/calc.py` — СВОЙ лёгкий калькулятор (Юлианский день, долготы Солнца/Луны, лунные состояния, знаки). Без swisseph/skyfield и без эфемеридных файлов.
3. **Голос**: `bot/voice/speaker.py` — edge-tts (Microsoft, бесплатный облачный синтез).
4. **Визуал**: `bot/visual/render.py` + `assets.py` — СВОЙ рендер на Pillow (расклады, share-карточки 1080×1080, одиночные карты, свечение, эффекты). Шрифты системные.
5. **i18n**: `bot/i18n/core.py` — СВОЙ микро-словарь RU/EN (детект языка, ключи, подстановки). Без gettext/Fluent.
6. **Телеграм**: aiogram 3.13+; handlers: start, reading, features, payment, admin; SQLAlchemy 2 + aiosqlite + alembic; оплата Telegram Stars (products/payload); posthog-аналитика + sentry.
7. **Контент**: 78 карт (22 мажор/56 минор), данные в data_major/data_minor/data_symbols, тесты 17 шт на pytest, стабилизация контента (docs/STABILIZATION_REPORT.md).

## Категории поиска (ищи по всем; англоязычные — ОБЯЗАТЕЛЬНО, русскоязычные тоже)
1. **Structured/надежный LLM-вывод**: улучшить instructor-слой: маршрутизаторы, лимиты/ретраи (tenacity, openai-retry, backoff), валидация и пере-генерация при невалидном JSON, дедупликация, streaming-агрегация. Проекты: instructor-эко, guidance/outlines, tenacity, litellm, openai-compatible роутеры.
2. **Астрономия/эфемериды** (замена/дополнение своего calc.py): skyfield, swisseph/pysweph, flatlib, kerykeion, pymeeus, culture/праздники (holidays), astrological patterns. Отметь: вес зависимостей, нужны ли эфемеридные БД, лицензия, активность, поддержка точных координат/таймзон.
3. **TTS/голос** (усиление edge-tts или локальная альтернатива): kokoro (RU-модели?), piper-tts (RU голоса), sherpa-onnx, chattts, melo-tts; сравнение качества RU, скорость, RAM, лицензии, offline-возможность.
4. **Визуал/генерация изображений** (улучшение рендера или ИИ-генерация карт-артов): ручные генераторы таро-артов (stable-diffution-класс: localai/automático-класс, comfyui-API, fal/sdwebui API), Pillow-экосистема (pillow, aggdraw, dehaze/эффекты, collage), шрифты с кириллицей для декоративных заголовков (Google Fonts переменные с лицензией OFL — т.к. сейчас системные).
5. **Telegram-бот фреймворки/инструменты aiogram 3.x**: aiogram-dialog, aiogram-fsm-extension, aiogram-detection-language, aiogram-rate-limiter, aiogram-stars (платежи), ссылки на проверенные шаблоны prod aiogram.
6. **i18n для бота**: замена своего core.py на что-то сильнее (Fluent/fluent.syntax, gettext+БД-строки, i18n-хранилища встроенные в aiogram) — где реальная выгода, а где оверкилл.
7. **Инфраструктура чат-бота**: расписание (apscheduler/aiocron — сейчас send_daily_push), кэширование (aiocache), очереди/джобы (arq/huey), rate-limit, анти-спам, мониторинг (prometheus+aiogram? sentry), автотесты айограм (aiogram contrib testing, pytest-asyncio паттерны), локализация TTS-скриптов.
8. **Контент таро (данные)**: конкурентные открытые деки/датасеты (78 карт, значения RU/EN), проекты таро-ботов с открытым кодом для референса архитектуры (telegram tarot bot github), символизм/словари. НЕ «чтобы скопировать», а для вектора качества.
9. **Платежи/монетизация Telegram**: не только Stars — подписки, реферальная система (сейчас есть реферал в модели User), фискализация? Ищи проверенные практики/библиотеки для TG-платежей.

## Скоринговая матрица (для каждого кандидата до включения в отчёт)
Оценивай от 1 до 5 и фиксируй баллы:  (1) активность — последний коммит ≤ 12 мес, (2) зрелость — звёзды/использование, тесты, CI, документация, (3) лицензия — MIT/Apache/BSD и т.п. (для коммерческого использования бота обязательна разрешающая), (4) сложность интеграции — вес зав-кей, совместимость с Python 3.11 + asyncio, (5) выгода для Moira — насколько реально усиливает конкретный узел. Отсеивай: заброшенные (>2 лет без коммитов, если только это не «done»-стабильная библиотека с большим usage), без лицензии, демо-обвязки, требующие платного API без бесплатного тира.

## Формат результата (ОБЯЗАТЕЛЬНО весь отчёт в ОДНОМ файле)
Файл: `docs/RESEARCH_PROJECTS.md` (в корне репозитория Moira; если папки нет — создай).
Структура:
```
# Разведка: проекты для усиления Moira
## Методика (2-3 строки: как искал, какие API/лимиты использовал, глубина проверки)
## 1. Сводная таблица (все узлы × отобранные кандидаты)
    колонки: Узел | Проект | URL (github/pypi) | ★ | последний коммит | лицензия | баллы (активн/зрелость/лиц/интегр/выгода) | вердикт
## 2. Подробно по узлам (для КАЖДОГО из категорий 1–9):
    - проект: URL, звёзды, лицензия, последний коммит, PyPI-майнер/version
    - что даёт Moira КОНКРЕТНО (назови модуль: adapter.py/calc.py/speaker.py/render.py/i18n/core.py/...)
    - как интегрировать (2-3 шага, API-сигнатура или класс)
    - риски/ограничения (вес, лицензия, обучение, платно/бесплатно)
    - альтернатива из твоей же короткой лиги (1-2 строки)
## 3. ТОП-5 проектов, которые реально усилят Moira (с обоснованием по матрице, НЕ по популярности)
## 4. Быстрое «не тратить время»: 5-10 проектов, которые ПОВЕРХНОСТНО ПОХОЖИ, но не подходят (почему)
## 5. Источники: URL всех страниц, которые проверил (не только главные)
```
- В каждой ячейке числа должны быть реальные (с проверенных страниц/API), не из головы.
- Если по категории отобрал 0 — напиши явно «не нашёл достойных, причина: ...», не раздувай кандидатами ради объёма.
