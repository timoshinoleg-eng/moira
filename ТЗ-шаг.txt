## ШАГ 5 — создать визуальные изображения (ИСПРАВЛЕННЫЙ код, сигнатуры верные)
ВНИМАНИЕ: cards_info требует объекты TarotCard: `{'label':str,'card':TarotCard,'reversed':bool,'name':str}`.
make_share_image(spread_title, cards_info, summary_str, footer). НЕ передавай dict как 'name'.
Создай папку и изображения, выполни РОВНО этот код:
```python
import sys, os
sys.path.insert(0, '.')
from bot.visual.render import make_spread_image, make_share_image, make_single_image
from bot.tarot.deck import build_deck
os.makedirs('artifacts/visual_review', exist_ok=True)
deck = build_deck()
def ci(tc, label, rev=False):
    return {'label': label, 'card': tc, 'reversed': rev, 'name': label}
info = [ci(deck[0],'Sun'), ci(deck[1],'Moon',True), ci(deck[2],'World')]
open('artifacts/visual_review/spread_ru.png','wb').write(make_spread_image('Расклад Ситуация', info))
open('artifacts/visual_review/share_ru.png','wb').write(make_share_image('Расклад Ситуация', info, 'Синтез: карты указывают на новые возможности.'))
open('artifacts/visual_review/single_card.png','wb').write(make_single_image('Заголовок','Подзаголовок', deck[0]))
open('artifacts/visual_review/single_rev.png','wb').write(make_single_image('Заголовок','Подзаголовок', deck[0], reversed_=True))
print('files:', [(f, os.path.getsize('artifacts/visual_review/'+f)) for f in os.listdir('artifacts/visual_review')])
```
Выведи: `[ШАГ5] files: [(имя, байт), ...]`. Если функция падает — [ОШИБКА] + строки ошибки, иди к шагу 6.
