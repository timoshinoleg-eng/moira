# Отчёт по улучшению внутреннего содержания Moira

| Область | Оценка | Комментарий |

## Основные найденные проблемы

1. **Младшие арканы шаблонные** — все 4 масти на один ранг имели одинаковый текст с заменой только темы
2. **Fallback примитивный** — просто склейка значений без синтеза и учёта позиций
3. **Промпт монолитный** — всё в одном тексте без разделения на уровни
4. **«Мой Аркан» неполный** — только 8 арканов из 22, scoring через % 22
5. **Нет символики** — карты не имели визуальных символов для RWS традиции
6. **Нет рефлексивных вопросов** — пользователь не получал вопроса для самостоятельного размышления

## Что изменено

### Content Patch 1: Карты и модель данных
- Расширена структура `TarotCard` с полями `ru`/`en` типа `LocalizedCard`
- Каждая карта теперь имеет: `upright`, `reversed`, `symbols`, `reflection_question`
- Для Старших Арканов добавлены 2–4 визуальных символа и рефлексивные вопросы
- Для Младших Арканов созданы уникальные значения для каждой масти×ранга (56 уникальных комбинаций)

### Content Patch 2: Расклады и синтез
- Обновлены позиции раскладов:
  - «Ситуация»: суть → скрытый фактор → следующий шаг
  - «Любовь»: твоё состояние → динамика связи → полезный фокус
  - «Выбор»: путь А → путь Б → критерий решения
- Добавлены описания позиций для LLM (`POSITION_MEANINGS`)

### Content Patch 3: Архитектура prompt
- Промпт разделён на 5 уровней:
  1. Голос и правила Moira
  2. Правила конкретного расклада
  3. Данные выбранных карт (с символикой)
  4. Контекст пользователя
  5. Формат результата
- Расширена Pydantic-схема: `headline`, `opening`, `card_interpretations` (с полями `position`, `card_name`, `orientation`, `core_message`, `symbolic_detail`, `context_connection`), `synthesis`, `practical_focus`, `reflection_question`, `voice_summary`, `share_summary`

### Content Patch 4: Fallback composer
- Создан детерминированный `compose_fallback_reading()` в `bot/tarot/fallback.py`
- Учитывает тип расклада, позиции, определяет паттерны
- Не создаёт ложную персонализацию
- Работает на RU и EN

### Content Patch 5: «Мой Аркан»
- Полная переработка: 22 Аркана вместо 8
- 6 вопросов по 4 ответа = 4096 комбинаций
- Scoring без `% 22` — каждый ответ даёт вес нескольким Арканам
- Все 22 Аркана достижимы (проверено полным перебором)
- Tie-break детерминирован (меньший номер Аркана)
- Полные описания для всех 22 Арканов: архетип, сильная сторона, теневая сторона, задача, девиз, вопрос

## Примеры улучшений до/после

### До (Младшие арканы):
```
Туз Жезлов: "Чистое начало: большой потенциал и шанс (действия, амбиции и энергия)."
Туз Кубков: "Чистое начало: большой потенциал и шанс (чувства, отношения и интуиция)."
```

### После:
```
Туз Жезлов: "Искра замысла: в руках появляется шанс начать что-то яркое и страстное (действия, амбиции и энергия)."
Туз Кубков: "Чувство переполняет края: новый эмоциональный опыт готов войти в жизнь (чувства, отношения и интуиция)."
```

### До (Fallback):
```
Суть: Новое начало и доверие жизни...
Скрытый фактор: Сомнения и страх перемен...
Следующий шаг: Пауза и новый угол зрения...
```

### После (Fallback):
```
Трактовка расклада
Без подключения ИИ карты говорят на языке символов и ассоциаций.

<i>Суть ситуации</i> (суть того, что происходит сейчас...): Искра замысла...
<i>Скрытый фактор</i> (скрытый фактор, внутреннее препятствие...): Сомнения и страх перемен...
<i>Следующий шаг</i> (наиболее конструктивный следующий шаг...): Пауза и новый угол зрения...

Общий вывод:
Ситуация раскрывается через три грани: то, что происходит сейчас, что остаётся скрытым, и куда стоит направить внимание. Карты показывают динамику, а не неизбежный итог.

Прислушайтесь к скрытому фактору — он может стать ключом к следующему шагу.
✦ Что из того, что вы пока не замечаете, влияет на ситуацию сильнее всего?
```
